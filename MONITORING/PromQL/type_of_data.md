##### Метрики 

```
counter   - может только увеличиваться 
            (пример - колличество обращений к серверу)

gauge     - измеритель - может увеличиваться и уменьшаться 
            (пример - колличество свободной оперативной памяти на сервере)

histogram - собирает наблюдения длительность запроса и размер ответа и считает их кол-во в настраиваемых диапазонах,
            еще предоставляет сумму всех собраных значений в области с настраиваемой верхней границей
            может - расчитывать средние значение
                  - расчитывать относительные изменения значений 

summary   - расширенная histogram + qantil за скользящий период


```

##### Типы данных в PromQL 

```
3 типа данных

instant vectors - содержит все значения метрики по запрашиваемой метки времени
                  (загрузака каждого ядра процессора в определенный промежуток времени)
 
range vectors   - возвращает все вектора за указанный промежуток времени 
                  (все метрики за время (t = last 3 min) по каждому ядру процессора)
                  нужно для получения изменения метрики во времмени 

Scalar          – простое числовое значение с плавающей точкой
```

##### Операторы PromQL

```

Математические операторы

   +  сложение  возможно использовать только с instant vector и scalar.
   -  вычитание возможно использовать только с instant vector и scalar.
   *  умножение возможно использовать только с instant vector и scalar.
   /  деление   возможно использовать только с instant vector и scalar.
   %  возвращает модуль исходных данных возможно использовать только с Iinstant vector и scalar.
      Пример: 13 % 5 результат будет 3
   ^  производит возведение в степень возможно использовать только с instant vector и scalar.
      Пример: 2 ^ 10 результат будет 1024



Операторы сравнения:
   ==    равно
   !=    не равно
   >     больше
   <     меньше
   >=    больше или равно
   <=    меньше или равно

Сравнение возможно только над scalar и instant vector. Оператор применяется к каждому
значению в исходном векторе, и все элементы данных, для которых не выполняется
условие сравнения, исключаются из результирующего вектора.
Если указан модификатор bool, то в результирующем векторе данные, которые
удовлетворяют условию сравнения, будут иметь значение 1, а не удовлетворяющие 0.
Сравнение двух scalar возможно только с модификатором bool.

Примеры 
node_cpu_seconds_total             (выведет все значения)
node_cpu_seconds_total > 3         (выведет все значения > 3)
node_cpu_seconds_total > bool 3    (выведет все значения (при этом значения будут равны1 или 0) при этом значение будет=1 если > 3 и значение будет=0  если Б 3)



Логические операторы:
   and      логическое И
   or       логическое ИЛИ
   unless   дополнение

Логические операторы возможны только между instant vector.

vector1 and vector2       приводят к вектору, состоящему из элементов vector1 , для которых в
                          vector2 есть элементы с точно совпадающими наборами меток. Другие элементы
                          отброшены. Название и значения метрики переносятся из левого бокового вектора.
     
vector1 or vector2        приводит к вектору, который содержит все исходные элементы (наборы
                          меток + значения) vector1 и дополнительно все элементы vector2 , которые не имеют
                          совпадающих наборов vector1 .

vector1 unless vector2    приводит к вектору, состоящему из элементов vector1 , для которых
                          нет элементов в vector2 с точно совпадающими наборами меток. Все совпадающие
                          элементы в обоих векторах отбрасываются.

Примеры 
node_load1 and node_cpu_seconds_total    - ничего 
node_load1 or node_cpu_seconds_total     - объединение 
node_load1 unless node_cpu_seconds_total - только метрики node_load1



Сопоставления векторов

Сопоставление векторов производит поиск одинаковых элементов в правом векторе для каждой записи левого вектора. 
Есть 2 типа сопоставления: 
     один к одному 
     один ко многим / многие к одному.


Сопоставление один к одному.
При сопоставление один к одному для всех элементов из правого вектора ищется
элемент, имеющий точно такой же набор меток (учитываются как имена метки, так и их
значения), и над такими парами производится операция.

Существует 2 модификатора для сравнения:
     on       – задает, какие labels необходимо учитывать при сопоставлении.
     ignoring – задает, какие labels должны быть исключены в процессе сопоставления.


Примеры
node_cpu_seconds_total{instance="ip_server1:9100",job="static_config"} + on(cpu, mode) node_cpu_seconds_total{instance="ip_server2:9100",job="static_config"}

В результате данного запроса вы получите суммарное потребление cpu по двум серверам.


Сопоставление один ко многим / многие к одному: в этом случае одному элементу
правого вектора может соответствовать несколько элементов второго вектора. Тогда
необходимо явно указать, какой вектор является главным. Это можно сделать с помощью
ключевых слов group_left и group_right.


Операторы агрегации:
     sum           – сумма
     min           – минимальное значение
     max           – максимальное значение
     avg           – среднее значение
     stddev        – стандартное отклонение
     stdvar        – стандартная дисперсия
     count         – количество элементов в векторе
     count_values  – количество элементов с одинаковым значением

Данные операторы могут использоваться с модификаторами by и without. 
       by        задает список labels, которые будут учитываться
       without   задает список labels, которые учитываться не будут.

Указание модификатора допускается как до, так и после запроса.

operator ([parameter,] <vector expression>) [without|by (<label list>)]

Примеры 

получить суммарное потребление cpu по всем инстансам в user mode
sum(node_cpu_seconds_total{mode="user"}) by (cpu)

получить суммарное потребление процессора в user mode по всем ядрам
sum without (cpu) (node_cpu_seconds_total{mode="user"})


Приоритет бинарных операторов

приоритет 1  ^
приоритет 2  * , / , %
приоритет 3  + , -
приоритет 4  == != , <= , < , >= , >
приоритет 5  and , unless
приоритет 6  or
```
